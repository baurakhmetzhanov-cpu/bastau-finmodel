# Финансовая модель проекта – веб-прототип

ТОО «Bastau Project». Прототип страницы для ввода и расчёта финансовой модели проекта, согласования по ролям и выгрузки утверждённых проектов в бюджет.

Расчёт повторяет Excel-файл «Финмодель_проекта_типовая_v4.xlsx» (листы «Финмодель проекта» и «Денежный поток») и Регламент бюджетирования v5 (пункты 7.4, 7.5, 12.4). Совпадение с Excel подтверждено тестами.

> Прототип работает на тестовых данных. Вход, права, хранение на сервере и обмен с 1С делаются в СЭД по техническому заданию [docs/ТЗ_СЭД_финансовая_модель.md](docs/ТЗ_СЭД_финансовая_модель.md).

## Что умеет

| Раздел | Содержание |
|---|---|
| Реестр проектов | список проектов по правам роли, статус, рентабельность, кассовый разрыв, маршрут (ФД или Бюджетный комитет) |
| Карточка проекта | ввод: тендер и доход, расходы, гарантии, денежный поток с мерами по кассовому разрыву; результаты: показатели, поток по месяцам, сценарии, журнал. Отправка в ПЭО – после просмотра результатов |
| Согласование | черновик → ПЭО → финансовый директор → Бюджетный комитет → утверждён → в бюджете; возврат на доработку, корректировка с новой версией |
| Портфель и бюджет | свод утверждённых проектов на бюджетный год по кодам статей БДР / БДДС, график, выгрузка в Excel |
| Параметры | НДС, КПН, порог рентабельности, ставки, сценарии |

Роли переключаются в шапке (демо-режим): руководитель проекта, ПЭО, финансовый директор, генеральный директор / БК, казначейство.

## Как открыть

* локально: скачать репозиторий и открыть `index.html` в браузере (интернет не нужен, библиотеки лежат в `vendor/`);
* GitHub Pages: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Страница будет доступна по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

Данные хранятся в браузере (localStorage). Для передачи данных между компьютерами – «Экспорт данных (JSON)» и «Импорт данных (JSON)» в реестре. Кнопка «Тестовые данные» возвращает исходные примеры.

## Структура

```
index.html                 страница
css/style.css              оформление
js/engine.js               расчётное ядро (чистые функции, без зависимостей)
js/store.js                хранилище прототипа, роли, статусы, тестовые проекты
js/app.js                  интерфейс
schema/project.schema.json контракт данных проекта (JSON Schema)
tests/engine.test.js       тесты ядра против эталонов из Excel
tests/golden.json          эталонные значения
vendor/                    Chart.js 4.4.1 (MIT), SheetJS 0.18.5 (Apache 2.0)
docs/ТЗ_СЭД_финансовая_модель.md  техническое задание для разработчиков СЭД
dist/finmodel.html         та же страница одним файлом (сборка: python3 build_dist.py)
```

## Тесты

Нужен Node.js 18 или новее:

```
node --test tests/engine.test.js
```

Три теста: базовый пример Excel (чистая прибыль 571 260, NPV 565 570, НДС 137 379), стресс-тест (аванс от суммы года, предоплата поставщику, денежное покрытие гарантий, ручной график, пессимистичный сценарий) и перенос в бюджет 2027 года по кодам статей.

## Ограничения прототипа

* нет авторизации: роль выбирается вручную, права проверяются только в браузере;
* данные не попадают на сервер и видны только на этом компьютере;
* не вносите реальные коммерческие данные, если репозиторий публичный.
